# Milestone 3: Route, Cancellation, and Seasonal Insights

## Description

This project analyzes flight data to provide insights on routes, cancellations, and seasonal patterns for Milestone 3 of the Infosys SpringBoard internship.

## Features

- **Route Analysis**: Top 10 origin-destination pairs, delay heatmaps by airport and route
- **Airport Analysis**: Busiest airports and average delays
- **Cancellation Analysis**: Monthly trends, cancellation types (carrier, weather, security, NAS)
- **Seasonal Insights**: Impact of holidays and winter months on cancellations

## Files

- `flight_analysis.ipynb`: Jupyter notebook with detailed data analysis and visualizations
- `app.py`: Streamlit web application for interactive exploration of insights
- `config.py`: Configuration file for paths and settings
- `requirements.txt`: Python dependencies
- `.gitignore`: Git ignore patterns
- `FInal_Flights_cleaned_data.csv`: Cleaned flight data

## Installation

1. Clone the repository
2. Install dependencies: `pip install -r requirements.txt`

## Usage

- Run the Streamlit app: `streamlit run app.py`
- Open the notebook: `jupyter notebook flight_analysis.ipynb`

## Insights

- Seasonal visual summaries of flight patterns
- Analysis of route congestion and cancellation factors
- Interactive visualizations for data exploration
